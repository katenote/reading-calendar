# 우리 반 독서 캘린더

초등학생이 실물 그림책을 읽고 독후활동을 한 뒤, 표지 스티커를 달력에 붙이는 사이트입니다.

## 개인정보

- 학생 이름, 표지 사진, 활동 기록, 교사용 비밀번호(변환된 값)는 각 기기의 브라우저(IndexedDB)에만 저장됩니다.
- 사이트에는 서버, 로그인, 분석 도구, 광고가 없습니다. 페이지의 Content-Security-Policy가 외부 전송(`connect-src 'none'`)을 막습니다.
- 글꼴은 저장소에 포함되어 있어 외부 글꼴 서비스에 접속하지 않습니다.
- 사이트 파일 자체는 GitHub Pages에서 내려받으므로, GitHub는 일반 접속 정보(IP 등)를 처리할 수 있습니다.

## 교사 안내

- 공용 기기에서는 학생이 쓰기 전에 교사가 먼저 교사용 비밀번호를 만들어 주세요. 비밀번호는 기기마다 따로 설정합니다.
- 교사용 잠금은 학생의 메뉴 접근을 막는 장치이며 암호화가 아닙니다.
- 내보낸 백업 파일에는 학생 정보가 들어 있습니다. 이 저장소나 공개된 곳에 올리지 마세요.
- 실명 대신 번호나 별명을 권장합니다. 표지 사진에 학생 얼굴이나 이름이 나오지 않게 해 주세요.
